# 躺平股息 V3

一个专注少量美股持仓与被动股息收入记录的移动端 PWA。

## 默认标的

- QQQI
- SPYI
- QNDX
- SCHD

也可以手动添加 NVO 或其他代码。每个标的都可单独填写“行情接口代码”，用于兼容不同市场代码格式。

## 动态数据

- 美元兑人民币汇率：Frankfurter，每日央行参考汇率，无需 API Key。
- 股票/ETF 价格：Alpha Vantage `GLOBAL_QUOTE`，免费版为最近交易日收盘数据。
- 历史及已宣布股息：Alpha Vantage `DIVIDENDS`。
- 近12月股息率：过去365天每股分红合计 ÷ 最新价格。
- 估算年化股息率：月度标的使用最近3次分红均值年化；季度标的使用最近4次分红均值年化。

Alpha Vantage API Key 由用户在设置页输入，只保存在当前浏览器，不会写入公开 GitHub 仓库。

## 自动股息到账流程

1. 同步 Alpha Vantage 股息数据。
2. App 获取除息日、宣布日、登记日、计划到账日和每股股息。
3. 按“除息日前一日”的历史买卖记录计算符合分红条件的股数。
4. 自动生成“已宣布”记录；计划到账日到达后显示为“待确认到账”。
5. 用户点击“确认到账”，填写实际到账日期、税费和净到账金额。
6. 只有确认后的记录才计入“今年已收净股息”。

规则：

- 同一标的同一除息日不会重复创建。
- 未确认记录会随远程数据更新。
- 已确认记录以券商实际入账为准，后续同步不会覆盖实际金额。
- 为避免首次同步产生大量旧记录，只自动生成最近120天及未来已宣布的股息。

## 数据策略

- 打开应用且数据过期时，可自动更新。
- 也可以在设置页或单只标的卡片中手动触发更新。
- 接口失败时保留上次成功数据，不会把价格或股息清零。

## 备份与隐私

持仓、交易、API Key 和股息记录均保存在当前设备浏览器的 `localStorage` 中。代码可以公开，但私人数据不会上传到 GitHub。换手机或清理浏览器数据前，请导出 JSON 备份。

## 本地预览

```bash
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080`。
